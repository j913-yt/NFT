# 答辩 PPT 页纲

## 讲解节奏

总讲解时间 5-7 分钟，建议按 10 页讲，每页约 35-45 秒。重点讲系统功能，背景和技术概念只服务于功能闭环。

## Slides

1. 封面
   - NFT数字藏品交易平台的设计与实现
   - 学院、专业、姓名、指导教师、日期

2. 课题目标
   - 数字作品存在确权难、交易追溯难、创作者收益延续难
   - 系统目标：实现数字藏品创建、确权、展示、交易和个人资产管理闭环

3. 系统总体架构
   - 前端展示层：Next.js / React
   - 后端服务层：Go / REST API
   - 数据持久层：MySQL / GORM
   - 智能合约层：Solidity / ERC-721 / EIP-2981
   - 分布式存储：IPFS / Pinata

4. 核心业务流程
   - 钱包签名登录
   - 上传媒体文件
   - IPFS 生成元数据
   - 合约铸造/上架
   - 市场展示交易
   - 订单同步管理

5. 功能一：钱包登录与权限基础
   - 后端生成 nonce
   - 用户钱包签名
   - 后端验证签名并签发 JWT
   - 登录态用于创建、上架、购买、个人中心

6. 功能二：数字藏品创建与链上确权
   - 支持图片、音频、视频
   - 校验名称、价格、文件类型、版税比例
   - 上传媒体与 metadata 到 IPFS
   - 调用合约生成 TokenID，并将链下镜像数据写入数据库

   - 详情页展示基础信息、价格、拥有者

   - 根据当前用户身份显示购买、上架或下架入口
