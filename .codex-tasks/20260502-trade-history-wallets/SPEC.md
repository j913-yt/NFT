## Goal

On the NFT detail page trade history section, remove non-functional tab text and show both usernames and wallet addresses for buyer and seller.

## Scope

- Update the frontend trade history section.
- Use existing backend fields if available.
- Do not add new fallback behavior or unrelated styling changes.

## Validation

- Run frontend lint.
- Verify `/nfts/22` renders trade history with buyer and seller wallet addresses.
